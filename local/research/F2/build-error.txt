(mini probe: u64-is-ulong=0 u64-is-ull=1), so all three returns agree.

type from unsigned long long, and deduced lambda return types must match
exactly. F2 Part 1 (Mac suite 612/612 + runners) and ST1 (Mac 616/616)
compiled this file cleanly; iOS builds on macOS are unaffected too.
Only Android/Linux breaks.
