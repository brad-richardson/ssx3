Local `~/dev/ssx3-work/GB3/pcsx2-ref/GSRegs.h:286-319` identifies CSR bit positions but does not define behavior. File:line references below are against these pins unless prefixed `ssx3/`.

The review's blanket "CSR isn't W1C" and "every CSR write clobbers FIELD" claims (`ssx3/docs/research/review-2026-09-23-frontier-2.md:48-50,149,195`) need narrowing. Bits 0/1 are W1C; bit 3 is currently ordinary writable storage. FIELD flips at each fork VBlankStart, but a CSR guest write can overwrite it (`ps2xRuntime/src/lib/ps2_memory.cpp:211-246`; `ps2xRuntime/src/lib/Kernel/EeScheduler.cpp:2623-2645`). This is a source observation, not a boot verdict.
