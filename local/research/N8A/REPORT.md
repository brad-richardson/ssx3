## One Part-2 runbook for the orchestrator to authorize separately

**Goal and discrimination.** One arm64 APK from fork `0cab7d7` plus N7's necessary Android pieces, opt-in in-process paraLLEl and pinned Turnip. Hypothesis: the app namespace resolves packaged Turnip and G43's HMI proc address reaches Granite, then the GS backend feeds and presents a stock race frame. Alternatives: Android compile/link failure; driver dependency/namespace failure; HMI/HAL failure; CPU fallback; system Vulkan; GPU init succeeds but no GIF/present. The log and APK gates below distinguish them. This runbook is a proposal, not an execution result.

1. **Inputs/source gate.** Create one local N worktree from `fork/ssx3` at `0cab7d7` (re-pin tip before work). Record `git status`, `git log -1`, G43 main/Granite HEAD plus SHA-256 of their tracked diffs, and the driver full SHA above with **two independent reads**. Keep guest codegen outside the fork (`PS2X_GAME_CODEGEN_DIR`), driver outside git, no generated guest source in the fork. Copy the tested G43 content and Granite submodules to bytesize under a bounded N work directory; verify tar/read SHA twice before build. One heavy bytesize job at a time.
2. **Allowed source changes.** In that N worktree, merge N7's codegen Gradle property, Android env parser/initializer and test source/registrations (`android/app/build.gradle`, `ps2xRuntime/include/ps2_android_env.h`, `ps2xRuntime/src/lib/ps2_android_runtime.cpp`, `ps2xTest/src/ps2_android_env_tests.cpp`, `ps2xTest/CMakeLists.txt`, `ps2xTest/src/main.cpp`); filter to arm64. Add Gradle properties for `PS2X_GS_SHADOW_PARALLEL=ON`, `PS2X_PARALLEL_GS_SOURCE_DIR=<pinned bytesize copy>`, and an out-of-tree `jniLibs/arm64-v8a` source dir. In `ps2xRuntime/src/lib/gs/ps2_gs_parallel_backend.cpp` plus one small helper/header if needed, gate a port of G43's `HMI`/HAL loader on Android and a new exact `PS2X_GS_TURNIP=1` env key. Load by library basename, log `dlerror`, HMI mapped path and HAL ops, pass non-null proc address to Granite, and fail closed if any step fails. Keep all non-Android and default paths intact. Use N7's `ps2x.env` approach to set `PS2X_GS_BACKEND=parallel`, `PS2X_GS_TURNIP=1`, CD image, I26-FAST pad route/clock and dev-only `PS2X_SKIP_MOVIE=1` before native startup. Keep N7's optional PNG, profileable, wake and pad-log changes out of this narrow functional gate unless the orchestrator needs them for its capture tool.
3. **Prebuild check.** Review exact CMake cache inputs and source diff; ensure test registrations preserve all current tests. Run `ps2x_tests` **from the fork worktree root** if a host suite is available. Stop on test failure or any missing pinned source/driver SHA. Up to **two APK builds total**, with the second only for one named compile/link or packaging fix; no tuning loop. Use N7's governed build shape, Gradle `assembleRelease` and diagnostics OFF. Record complete command, HEAD, cache flags, exit code and bounded error tail. A linker failure is tabled, not presumed to be a Turnip problem.
4. **APK gate before install.** Check `lib/arm64-v8a/libps2EntryRunner.so` and `lib/arm64-v8a/libvulkan_freedreno.so` exist in the APK, no x86_64 member, and the Turnip member's uncompressed SHA equals `717812c3…1ac29d`. Record APK and runner build ID/SHA with two reads; check `PS2X_GS_SHADOW_PARALLEL=ON`, local paraLLEl path and external codegen in the final Gradle native CMake cache. If any gate fails, stop before install.
5. **One Odin launch.** Claim `/data/local/tmp/mg/LEASE`; install the gated APK even if already present, verify installed `base.apk` SHA twice, then check charging and ≥20% battery and `dumpsys window policy` `KeyguardServiceDelegate showing=false` (ask Brad to unlock if needed). Stage only the `ps2x.env`/route/stock inputs required by N7, with two matching SHA reads for any pinned input. Launch at most once, using I26-FAST and a **600 s wall cap**, 120 s no-progress cap, ≤16 MiB combined text logs and ≤3 MiB captures. Capture the first visible race frame or report where progress stopped. Collect app PID-scoped logcat containing env keys, HMI mapped file, HAL ops, Granite GPU/API/driver and `[gs:parallel]` selection/init/counters. Force-stop `com.ps2x.runner` immediately after the run on every exit path, confirm PID absent, release lease, and bound/close receipts. A locked device, low battery or held lease delays launch; a runtime failure ends the brief.
6. **Acceptance table.** Report APK/driver/runner SHAs and build IDs; build/link result; `dlopen`/HMI/HAL result; Granite identity against G43's Turnip/system pairs; `init ok`, `gif>0`, `presents>0`, `null_scanouts`, and the saved frame/tick.
