# N8D5A — same-stream Odin scanout probe design

Read-only design. A/B/C means **A**: Turnip/paraLLEl produces a sparse `shot.image` on Odin; **B**: `shot.image` is complete but the current transfer/readback path loses content; **C**: a separate live integration/timing path differs from standalone replay. These are predictions, not findings.

Probe 3 still returns data through a host-visible buffer; if that buffer map also fails, A/B predict the same result. Probe 2 cannot separate A/C on a sparse live surface. **No current Android tool here truly separates A/B:** the only sampled-image display example is compiled against G43's `null` Android platform. The smallest additional mechanism is a real Android surface/swapchain (or another independently verified GPU-visible output) bound to the same `shot.image`, plus a `PS2XGSC1` adapter for standalone replay. `ssx3-work/G43/parallel-gs/Granite/application/platforms/CMakeLists.txt:5`–`14` shows the alternative Android GameActivity path and its package dependencies; feasibility and budget require a separate build check.

## Format compatibility

G43 `parallel-gs-stream` calls `GSDumpParser::open_raw` and `iterate_until_vsync` (`ssx3-work/G43/parallel-gs/tools/gs_stream_replayer.cpp:175`, `ssx3-work/G43/parallel-gs/tools/gs_stream_replayer.cpp:242`). `open_raw` only opens the file and sets `is_raw=true`; it checks no `PS2XGSC1` magic (`ssx3-work/G43/parallel-gs/dump/gs_dump_parser.cpp:60`–`67`). Its event loop reads one-byte `GSDumpPacketType`: transfer=0, vsync=1, read-FIFO=2, priv-registers=3, followed by that format's fields (`ssx3-work/G43/parallel-gs/dump/gs_dump_parser.hpp:18`–`24`, `ssx3-work/G43/parallel-gs/dump/gs_dump_parser.cpp:145`–`195`). The fork's parser requires eight-byte `PS2XGSC1` magic, then four-byte length-prefixed kind/tick/payload records; kind 1 is a GIF packet and kind 4 a VBlank marker (`ssx3-work/N8D4/PS2Recomp/ps2xTest/src/ps2_gs_replay_tests.cpp:32`–`43`, `ssx3-work/N8D4/PS2Recomp/ps2xTest/src/ps2_gs_replay_tests.cpp:159`–`165`, `ssx3-work/N8D4/PS2Recomp/ps2xTest/src/ps2_gs_replay_tests.cpp:257`–`285`, `ssx3-work/N8D4/PS2Recomp/ps2xTest/src/ps2_gs_replay_tests.cpp:320`–`343`). **G43's stream replayer does not accept `PS2XGSC1` directly.** Passing the path unchanged would parse its magic as raw event bytes.

## Recommendation

Part 2 should pursue **probe 1 only after its missing Android surface mechanism is proven**. First scope and build an Android activity/native surface and Vulkan swapchain using a surface path that actually runs on Odin; G43's current `null` app is unusable (`ssx3-work/G43/parallel-gs/CMakeLists.txt:55`–`59`, `ssx3-work/G43/parallel-gs/Granite/application/platforms/application_null.cpp:28`–`35`). Require a visible nonblack control pattern and a held screenshot **before** installing the stream adapter or spending a 1.1 GB transfer. If that control fails or platform/package integration exceeds the Part-2 budget, stop and return the platform gap; do not treat a black screen as `shot.image` evidence. If it passes, add bounded `PS2XGSC1` replay and same-image map, matching runtime `VSyncInfo`/GS options (`ssx3-work/N8B1/PS2Recomp/ps2xRuntime/src/lib/gs/ps2_gs_parallel_backend.cpp:246`–`253`, `ssx3-work/N8B1/PS2Recomp/ps2xRuntime/src/lib/gs/ps2_gs_parallel_backend.cpp:426`–`432`, `ssx3-work/G43/parallel-gs/tools/gs_stream_replayer.cpp:163`–`169`). **Discriminatory gate:** verify stream SHA, EOF/counts, tick/page/dimensions/PMODE, pinned Turnip, and the surface control; then compare held tick-2050 sampled surface with mapped RGBA. The three expected pairs are in probe 1. Stop as **OTHER/inconclusive** for failed control, ambiguous screenshot, parse/count mismatch, wrong page/tick, or any off-table pair. No causal or device-fault verdict follows from this design.

No build, boot, device contact, source edit, or LSP result was produced. The G40/G41 conclusion remains confined to its earlier dump.
