# AU10 — folded tip hangs on the title with sound off (muse, 2 h, Mac)

## Facts
- GA1 (`local/research/GA1/REPORT.md` "Folded-tip sound-off hang"): on fork `ssx3` `56a5e8a`, a boot **without** `PS2X_SOUND=1` sits on the title to t2400 (9 small packets/tick, all 31 pad presses ignored). With `PS2X_SOUND=1` it races (F1, SB1, GA1 B2). Pre-fold GB8 (`f949ff0`) raced with sound off, so AU9's SPU voice layer (`8af43c1` → folded `3120bba`) introduced the dependency.
- AU9 design (`local/research/AU9/REPORT.md`): SND HLE mixes music + SPU voices at 48 kHz; SNDDRV `updatevoices` port with the ENVX retry (key off waits until ENVX == 0) and status word/NAX slots; host output initializes only when `PS2X_SOUND=1` (`ps2_runtime.cpp:1116`).

## Correct-behaviour model
Guest-visible SPU state (ENVX, NAX, status words, voice end flags) must advance on **guest time** (the SND HLE tick), whether or not a host audio device consumes samples. Host output only drains a buffer. Observable that separates "voice state advances only in the host callback / only when output is initialized" from "something else": with the fix, (a) a sound-off boot races, and (b) **det-hash lines are identical sound-on vs sound-off** to t2400 (the guest can't depend on host audio). If (b) fails even with sound on vs sound on, report that too (host-audio timing leaking into guest state).
