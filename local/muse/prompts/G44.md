## Why

Two reasons. (1) Product path: the GPU GS backend. G43 showed paraLLEl on
the Odin under Mesa Turnip renders the G13 scene to PSNR 70–78 dB of the
Mac (first two frames bit-identical); the proprietary Adreno driver is the
fault, so Turnip gets bundled (orchestrator verdict). The next step is
paraLLEl fed by the live recomp instead of a PCSX2 dump. (2) Cross-check
for the recomp's missing 3D (rider absent on Select Character, race
world near-black): if paraLLEl, fed the same GIF stream, draws the rider
while the CPU backend doesn't, the fault is in the CPU backend (H2). If
both miss it, it's upstream of the GS (VU1/VIF: E33 is testing that).

## Design (synchronous shadow, no threading yet)

- Tap at the GB1 seam: the `GifArbiter` process-packet callback
  (`ps2_runtime.cpp` ~750, `m_gifArbiter.setProcessPacketFn`), plus the
  privileged-register writes and host↔local transfers GB1 §1a lists. Feed
  paraLLEl `gif_transfer` / `write_register` / priv stores in the same
  order the CPU backend sees them. The CPU backend stays the presenter;
  paraLLEl's output is read back per vsync for comparison only.
- Env-gated `PS2X_GS_SHADOW=parallel` (+ `PS2X_GS_SHADOW_DIR` for per-vsync
  PNG pairs, window `_FROM`/`_TO`, hard cap 200 pairs). Unset = zero
  behavior change and no paraLLEl init.
- Code lives on a **G-owned fork branch** `g44-parallel-shadow` cut from
  `ssx3` (`e57b5f8`) in a separate worktree
  `~/dev/ssx3-work/G44/PS2Recomp` (`git -C ~/dev/PS2Recomp worktree add …`).
  Don't touch `~/dev/PS2Recomp`'s checkout (E33 owns it). paraLLEl/Granite
  come from G43's internal working copy (`~/dev/ssx3-work/G43/parallel-gs`,
  = `wip/ssx3-snapshot` + G43 hunk) as a CMake subdirectory/FetchContent
  from a local path; no network fetch of the GS sources.

## Runs (Mac, P-lane lease; E33 also boots: wait for the lease, never preempt)

- Boot S1: `PS2X_SKIP_MOVIE=1`, E32's (b) pad script to the **title** then
  **Main Menu**; shadow on; PNG pairs over ~20 vsyncs each. Cap 150 s.
- Boot S2: script to **Select Character settled** (E31/E32 route); shadow
  pairs over ~20 vsyncs. Cap 300 s.
- Per pair: PSNR, differing-pixel count, bounding box of differences, and
  one side-by-side PNG per screen viewed by eye. **Say plainly whether
  paraLLEl's Select Character frame shows the 3D Zoe model.**

## Budgets and stop rules

- Builds as needed (one configure), 2 boots (+1 retry if the lease holder
  crashed the run), time box 5 h. Internal byte cap 15 GB for
  `~/dev/ssx3-work/G44`; `local/tooling/disk_budget.sh` at start and end.
- If paraLLEl can't init under MoltenVK in-process or the shadow path
  crashes the runtime, table it (first error, stack) and stop.
- No push of any branch (the orchestrator decides after the gate). The
  suite must stay green from the fork root with the flag unset
  (`git diff --stat 14b1e5cb HEAD -- ps2xRuntime/src/runner` empty).
