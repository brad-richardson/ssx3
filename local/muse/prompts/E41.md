## Why

(→ `0x434990`) the recomp lacks; the chain arenas sit at different heap
addresses; and E40 Part 7 proved the recomp's CALL tags (at `0x63b994`,
`0x63bbe4`, `0x63bea4`, `0x63c134`, value `0x435bd0`) are **never written by
EE code** in the whole boot: they arrive via a path that bypasses the guest
WRITE macros (IOP/SIF DMA from CD data, or a host memcpy). So the scene's
display list is loaded data, and the recomp loads different data (or loads it
differently). T52 logs PCSX2's CD reads boot → Select Character.
