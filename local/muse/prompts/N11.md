## Deliverable table (the point of the lane)

Stages: guest code; EE runtime helpers (memory/TLB/syscalls); VU1 interpreter (split hazard bookkeeping vs execute); VIF1/DMA; GIF/GS packet handling; paraLLEl CPU-side submit; SND/audio; scheduler/sync/waits; PLT; libc/kernel; other. One row per thread for GameThread, GsWorker, audio, main (CPU-s per guest frame). Also GPU busy % (`/sys/class/kgsl/kgsl-3d0/gpubusy` sampled every 5 s) and thermal status per phase. Every symbol→stage mapping listed in an appendix so it can be checked.
