# Q2 — tool: `sbr-census.py`, the signed-branch census over generated code (local Qwen, dense, 1.5 h)

## Why
The review (`docs/research/review-2026-09-25-fable.md` §2 row S6 and "Cheaper companion") wants the signed-branch census re-run after every codegen regen, so we can track how many signed-branch sites are "safe by construction". Build it as a reusable script whose output a check can verify against known numbers.

## Spec
- Path: `local/tooling/ee/sbr-census.py`. Usage: `sbr-census.py <codegen_dir> [--json out.json]`. Stdlib Python only.
- Input: generated C++ files under `<codegen_dir>` (only files matching `*.cpp`). Two codegen generations exist:
  - old (pre-SB1): `~/dev/ssx3-work/codegen-ssx3-pre-sb1` — signed branches look like `GPR_S32(ctx, N) < 0`, `>= 0`, `<= 0`, `> 0` on a `branch_taken`-style line (open a few files and confirm the exact text before writing regexes);
  - new (SB1): `~/dev/ssx3-work/codegen-ssx3` — the same sites use `PS2X_SBR_LT(`, `PS2X_SBR_GE(`, `PS2X_SBR_LE(`, `PS2X_SBR_GT(` macros.
- Output (stdout, and JSON with `--json`): total signed sites; count per predicate kind (LT/GE/LE/GT); number of files containing at least one; and for each site the **nearest preceding writer** of the tested register inside the same function (the review's S6 categories: `SET_GPR_S32`, `SET_GPR_U64` 64-bit add, `SET_GPR_U32`, `SET_GPR_VEC`, and/or/xor, SLT, MF*, live-in at function entry, none within 400 lines) — as counts per category.
- Known answers to check against (put these in a `--self-check` flag that runs both dirs and asserts):
  - old codegen: **4,466** signed sites (E54E and the review's census); 3,231 nearest writers `SET_GPR_S32`, 686 64-bit add (review S6; allow the category counts ±2 % since the review's pass was a one-off regex, but the total must be exact);
  - new codegen: **623 files** reference `PS2X_SBR_LT` (F2 Part 1) and the total site count equals the old total (4,466).
  If a known answer doesn't match, report the actual number and the three example sites where your regex differs; don't tune the regex to hit the number without saying so.
- Deliverable: the script (with a usage docstring), `local/research/Q2/REPORT.md` (commands run, outputs for both dirs, self-check result, any mismatches explained), commit `[Q2] …` (explicit paths, `git add -f`, trailer `Orchestrated-By: opencode`). No push. Edit nothing else. Never copy generated code into git.
