## Context

The eventual goal is a true 120 Hz simulation (about twice the stock
update rate at normal speed). Before designing it we need to know how the
PS2 game advances time: fixed per-vsync steps with hard-coded constants, a
measured delta time, or a mix. The GameCube build's answer is recorded in
`docs/reserve.md` and `docs/archive/todo-2026-09-22.md` (search "timestep",
"dt", "1/60", "vsync"); the PS2 build's game-side patch sites were
published (search `docs/` and `local/research/` for "timestep" /
"patch sites"). Use those as leads, not as answers.
