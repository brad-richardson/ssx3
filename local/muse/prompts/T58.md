## Why

T56 found that in healthy PCSX2, toSPR DMA stages the rider item
(`0x70000000`, w0 = `0x1b0` = mode 6) from EE `0x809670..0x80967c` every
vsync. The same holds for item `0x500` from `0x809b70..`. But no EE store
writes those buffers during the settled window. w0–w2 were written before
the statefile point. w3 changes every vsync through a path T56 didn't hook
(fromSPR or SIF DMA). T57 found zero VU0 programs and zero VIF0 traffic at
settled Select Character. The recomp never gets a 0x1b0 item (E43/E44).
We need PCSX2's writer of these buffers **at scene build**.
