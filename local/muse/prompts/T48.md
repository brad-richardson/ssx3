frame only the HUD shows (terrain is a dark silhouette, no rider, no sky),
and on Select Character the 3D Zoe model is missing (T47). The recomp runs

that exits silently when spent** (`ps2_runtime.cpp:753-788`,
`ps2_vu1_core.cpp:1636,1827`); XGKICK output goes out as PATH1. We need
the healthy numbers to test that against.

Hypotheses the recomp side (next E brief) will discriminate using your table:
- **H1 VU1 budget truncation:** healthy VU1 programs at these screens run
  longer than 65,536 cycles from start to E-bit, so the recomp cuts them
  off before XGKICK: PATH1 draws missing in the recomp.
- **H2 GS-side fault:** PATH1 draws arrive in similar counts but render
  wrong (texture/CLUT/Z/alpha): counts match, pixels don't.
- **H3 VU1 math/unpack fault:** draws arrive but with degenerate or
  off-screen geometry: counts match, bounding boxes don't.
Your job is the healthy side of each observable: per-vsync draw counts by
path, per-draw tuples, and per-program VU1 cycle lengths.
