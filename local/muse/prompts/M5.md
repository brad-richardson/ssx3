2. **XFB fidelity.** In the mask walk, also decode the XFB copy of the
   recorded frame: the EFB-copy BP write (`BPMEM_TRIGGER_EFB_COPY` 0x52
   with the XFB bit) and its destination (`BPMEM_EFB_ADDR` 0x4b), stride
   (0x4d) and the copy rectangle (0x49/0x4a) → destination byte range in
   guest RAM. After the original frame (before the first restore) hash
   that range (`RamHash`); after every replay hash it again before the
   restore. Receipt: per-replay `xfb_equal` in the probe row and a count
   `xfb_equal=N/200` in the `done` detail. Also record the range
   (address, bytes).

3. **Side-effect counters, fail-closed.** Per replay, before/after
   deltas of: texture-cache entry count (`g_texture_cache` map size —
   find the accessor or count via the public API), `m_pending_efb_copies`
   size if reachable (else the `FlushEFBCopies` count via the after-frame
   listener below), `g_presenter->FrameCount()`, `after_frame_event`
   triggers (register the header's own listener on
   `system.GetVideoEvents().after_frame_event` for the duration of the
   sequence and count), PE pending flags (`PixelEngineManager` token /
   finish pending, read via its `DoState` into a scratch PointerWrap or
   public getters), VI register hash, `OpcodeDecoder::g_record_fifo_data`

   and stop the sequence). Receipt: a per-replay row with the deltas and
   a 200-row summary table (min/max of each delta). Nothing is suppressed
   in this step: it measures.

4. **Replay-owned XFB destination.** In the replay copy of the execute

   live XFB untouched. Then compare: hash(scratch region after replay k)
   vs hash(live XFB after the original frame) → `xfb_equal_scratch=N/200`;
   and hash(live XFB) must be unchanged across the sequence
