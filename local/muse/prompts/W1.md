## Facts

- Brad (09-23): make the game's widescreen mode the default, as on the
  GameCube build.
- On the GameCube, the game's **own Options > Widescreen setting** renders
  the 3D scene anamorphic (horizontally squeezed 16:9 in a 4:3 buffer),
  and the host stretched the output to 16:9. Dolphin's automatic
  detection wasn't stable across menus and gameplay (old
  `native/ios/App.mm`, commit `a8e624b`).
- The PS2 version most likely has the same option. PCSX2 also ships a
  widescreen *patch* for SLUS-20772 (CRC `08FFF00D`); NetherSX2 ran it in
  the ps2-gate. Prefer the game's own option; the patch is the fallback.

## Work

1. **Find the setting.** Where does SSX 3 PS2 keep the widescreen flag?
   Look in the options menu code, the options/profile struct, and the
   memory-card save; use the helpers and a boot that visits Options if
   needed. Table:
   - the address/offset;
   - its default;
   - who reads it (the projection/FOV code and the HUD layout).

   Cite the code for each.
2. **Default on:** a boot-time HLE/runtime setting (`PS2X_WIDESCREEN=1`
   default on, `0` restores 4:3) that sets the flag the way the options
   menu does, after the game initializes its defaults. No ELF edit. Make
   sure a saved profile doesn't silently override it, or say what it does.
3. **Presenter:** when the flag is on, present 16:9 (stretch the anamorphic
   frame). `PS2X_ASPECT` still overrides. The iOS/Android presenters too,
   via the shared geometry header.
4. **Validate** (≤3 boots, one slot each, escalated, wait for a free slot):
   the title, main menu, Select Character and the race at 16:9. View each
   yourself and check that 2D/HUD elements aren't stretched wrongly,
   against PCSX2 with its widescreen patch if you need a reference on
   bytesize (optional).
