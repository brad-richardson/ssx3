## Why

Twice now a whole class of game behaviour silently vanished because a real
function start sat inside a merged function:
- menu 3D (E46: 19 entries);
- part of the sound mix (AU5: `0x3c9518`/`0x3c9520`/`0x3c95f0`, called
  26k times per boot through a function-pointer table).

The runtime's `ContinueToTarget` policy returns with a stale `$v0` and
reports only the first miss. The review counts **4,045 interior
`addiu $sp,$sp,-N` prologues** inside 1,615 functions (858
data-referenced), and only 22 are registered.

## Work

1. **Recompiler rule:** every interior `addiu $sp,$sp,-N` that follows a
   `jr $ra` (plus its delay slot), and every data-referenced interior
   address that is a plausible leaf start, becomes a resume entry
   automatically. It's the same mechanism as `extra_function_starts`, and
   harmless if never entered. Table the counts:
   - added;
   - already present;
   - rejected, and why (for example, an `addiu sp` mid-body that isn't
     after a return).

   Include AU5's three and E46's 19 as self-checks: they must be found.
2. **Runtime policy:** `PS2X_MISSING_FUNCTION_POLICY=stop|continue`,
   **default `stop` in dev builds** (abort with the target, source and
   call chain), `continue` in release. Add a per-target miss counter
   printed at exit. Also count unknown syscalls and unhandled RPCs.
3. Regenerate the codegen and build (taps OFF). The suite must fully pass.
   Report the generated code size and runner `.text` against
   `b9647f5`'s.
4. **Gate boots:**
