## Method and budgets

- `du -sk` per top-level entry (logical sizes; ExFAT allocates 1 MiB per
  file, so also give the file count, `find … -type f | wc -l`, so the
  orchestrator can estimate the space actually freed). Depth 2 only for
  entries over 20 GB or with mixed classes.
- Reference check: `grep -rl` the entry name across `docs/`,
  `local/muse/prompts/`, `local/research/V1/`, and the REPORT/CHECKPOINT
  files of E31, E32, G42, PF1, T47, N3. Only references from open items
  count toward KEEP-LIVE; a reference from a closed report is history.
- Time box 90 min. No hashing of anything over 1 GB. The SSD can
  disconnect at random (no data loss): if it drops, wait for remount and
  resume; note it.
- Don't read inside NOT-SSX3 entries beyond their size.
