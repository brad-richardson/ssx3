## Mechanism and tests

1. Add `PS2X_ENABLE_DET_HASH_TAP`, default OFF. Its OFF binary must
   contain no 32 MiB scan call or VU1 count increment. ON: parse
   `PS2X_DET_HASH_EVERY` once per scheduler instance. Unset/empty/exact
   decimal `0` disables; decimal `N>=1` emits on `vsync % N == 0`.
   Reject signs, whitespace, suffixes and uint64 overflow; one bounded
   error then off. At `EeScheduler.cpp:2739` after the tick/guest flag
   writes and callback/IRQ queueing, stream RDRAM (32 MiB), scratchpad,
   VU1 data, VU1 code (16 KiB each), then a count encoded as eight
   explicit little-endian bytes. Emit four region XXH64s and combined
   XXH64 with tick, EE cycle and numeric count. Null pointer fails
   closed. No guest read/write, full-memory copy or GS/VRAM scan.
2. Count **new VU1 `execute()` starts** in the VU1 interpreter instance;
   exclude `resume()`/MSCNT and VU0. Reset with that instance. This
   covers VIF1 MSCAL and EE CMSAR1, whose call sites are in E55C1.
   Make count available to the scheduler only in the ON build. Cap
   output at 4096 lines/process and 256 bytes/line, one short line
   per selected tick; report when cap stops output.
3. Focused tests: official XXH64 seed-0 known vector(s), incremental vs
   one-shot equality, one-byte perturbation in each region, region
