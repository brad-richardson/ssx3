# Implementation plan, September 15 2026

Where things stand after the September 14-15 push, and the order of work
from here. Facts are in the linked docs; this file is the plan only.

## Established

- **Course scripting is the shipping path.** `tools/gamecube_lun.py`
  assembles Luno bytecode (round-trips all 238 stock programs) and
  `gamecube_startgate.py --countdown-script` writes a program into the
  course's event slot (program 3). Named-event closures register and fire;
  builtin 2 `DeadNode` removes instances; builtin 0 then builtin 22 cycles
  the light flipbook. The start gate is complete on this path
  ([scenery notes](gamecube-scenery.md)).
- **Behaviour classes are how stock objects react.** Definition word 2 is a
  class oid into the script record's 24-byte class table; slot 1 (create)
  and slot 2 (rider contact) name programs. `gamecube_interactions.py
  --pushable-blocks` binds the 63 mode-3 placements to an AnimTeeter
  program (`local/research/startgate/breakables-recipe.md`). Installed on
  the iPhone as `gc-gari-interactions-001`; a block moving on contact is
  not yet observed.
- **Local-matrix models import** (`--compose-local-matrices`, 647 models).
- **Aloha Ice Jam Showoff, phase 1** builds into the ASS1 slopestyle slot
  (terrain, paths, scenery, rails) through per-course presets
  ([Aloha notes](aloha-conversion.md)).
- **Delivery targets:** Mac and iPhone native runtime now; Odin later, also
  native. The ISO/Dolphin path is dropped.
- **GPU box:** `ssh bytesize` (Tailscale, user bradr) reaches the RTX 4070;
  WSL2 venv `~/upscale` has torch 2.6 cu124 and spandrel.

## In flight (agents, September 15)

1. **Aloha static collision.** Scenery importer emits
   `scenery.instance_source_ids`; the 0xFFFF material index is handled;
   builds gc-aloha-004 (scenery) and -005 (collision). Land when it returns.
2. **Boot-time course redirect.** Runtime hook patches Snow Jam's event
   row in guest RAM from a manifest (archive name, code, location id, mode,
   names) so no DOL byte changes and the module is not regenerated.
   Wired into `gamecube_course_check.py --course-manifest`. Proof runs:
   renamed stock archive, then the Aloha archive as slopestyle. This is
   both the Aloha ride unblock and the course-picker foundation.
3. **Breaking glass.** Donor glass panes and trigger volumes identified,
   stock ABC1 shatter program decoded, `--breaking-glass` binder and a
   static candidate gc-gari-interactions-002.

5. **Crowd and remaining scenery animation.** The crowd prefabs carry

6. **Texture remaster prototype (independent track).** Runtime texture

   key so packs stay portable.

## Rules that held up

- One native runtime at a time; check `pgrep -f gamecube_course_check.py`
  before launching, and never wait with a loop whose command line contains
  the pattern it greps for.
- Every claim of "works" needs a screenshot or observer line, and the
  control run that would have shown the failure.
- Keep new behaviour opt-in behind flags; rebuild the Garibaldi lineage
  and compare archive hashes after any importer change.
