# Current numbers ledger

One table of the numbers still worth quoting or comparing against. Documents
cite rows here instead of restating values.

- **Status:** every row is live unless its metric says *provisional* or
  *pre-sound fold*. Contested (conflicting evidence) and void (measured
  broken) numbers are never quoted; stale ones are re-run before quoting.
- **Speed** comes only from clean builds: `PS2X_ENABLE_DIAG_TAPS=OFF`,
  runtime/aggressive logs off, no frame dumps, function traces or watch
  sets. It is stated as guest vsyncs per wall second ÷ 59.94.
- **Diagnostic builds** are labelled as such; their rates and boot walls
  are never quoted as speed.
- **Presents/s are not guest frames**: the host presents ~60/s whatever
  the guest does.
- **Race numbers need ≥2 runs** (the RNG is seeded from the RTC) and a
  viewed frame showing racing; a one-run number is marked provisional,
  and menu pace is never reported as race pace.
- **Pre-sound fold:** speed taken before the 09-24 sound-HLE fold (fork
  `959f4ea`) is marked "pre-sound fold; re-measure before comparing".
- **Host labelling:** every row names the device/host and the build (fork
  rev or APK SHA). Mac wall rates are contaminated when other lanes run, so
  note host load; verdict-grade runs get an exclusive host and device.
- **Under a cap**, report host CPU-ms per guest frame (or busy fraction);
  speed saturates at 1.00 and hides wins as idle.
- Removed/superseded rows: git history (`git show dfadb56a:docs/numbers-ledger.md`).
